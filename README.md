A paper-trading bot for pump.fun launches: buys fresh coins showing early buy flow with small capped size, exits fast on take-profit, stop-loss, trailing stop, or max hold. One round trip per mint. Built by an AI agent for make.fun's “Pump.fun Paper Sprint: Any Bot Can Win” bounty, $2 in USDC.

## Run it

```sh
node cli/makefun.mjs grade-local --kit . --bot . --driver process
```
